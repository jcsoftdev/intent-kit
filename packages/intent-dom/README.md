# @jcsoftdev/intent-dom

DOM adapters for the intent kit: target registry, revealer and announcer. Part of the [intent kit](../../README.md).

## Install

```sh
pnpm add @jcsoftdev/intent-dom @jcsoftdev/intent-core
```
