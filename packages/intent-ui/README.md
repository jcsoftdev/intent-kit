# @jcsoftdev/intent-ui

Ready-made assistant components for the intent kit on top of @jcsoftdev/ui. Part of the [intent kit](../../README.md).

## Install

```sh
pnpm add @jcsoftdev/intent-ui @jcsoftdev/intent-core react react-dom @jcsoftdev/ui
```
