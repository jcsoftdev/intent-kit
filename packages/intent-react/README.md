# @jcsoftdev/intent-react

React bindings for the intent kit: provider, session and target hooks, and the ui bridge. Part of the [intent kit](../../README.md).

## Install

```sh
pnpm add @jcsoftdev/intent-react @jcsoftdev/intent-core react react-dom
```
